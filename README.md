# 航策 · 战略研究知识库 离线 demo v1.2

最新完整离线包：[aero-DB-offline-v1.2.zip](aero-DB-offline-v1.2.zip)。请使用 v1.2，v1.1 归档保留。

## 启动和登录
电脑需要 Python 3.8+、现代浏览器；无需 pip 和外网。
Windows：完整解压到新目录，双击 start.bat。Mac/Linux：运行 sh start.sh（Mac 也可 start.command）。
浏览器会自动打开词云登录页；默认账号和密码均为 **admin**。
若未自动打开，访问启动窗口打印的网址。默认使用8000端口；被旧程序占用时自动尝试8001–8010，避免误打开旧版本。
不要直接双击 HTML；直接打开时会提示使用启动脚本。

登录信息由本地服务校验，密码以加盐哈希保存；退出登录后需重新输入账号密码。
本版内置本地 admin 账号，未接入企业账号系统；资产负责人记录为当前账号显示名 admin。
仍仅监听本机127.0.0.1，不是供多台电脑共享访问的服务器版。

## v1.2 功能
- 词云账号密码登录，登录后加载工作台；刷新保留有效会话，启动程序重新打开登录入口。
- 模板新增/编辑包含交付对象、使用场景、主要内容（最多3个标签），报告工作台可继续使用模板。
- “维护与质量”提供“新增数据”按钮。
- 下载CSV模板，填写后预览校验，再确认批量追加素材；负责人取当前登录账号，编号自动分配。
- 导出资产备份为UTF-8 BOM CSV，兼容中文、逗号、引号、多行正文；可通过“导入备份”恢复CSV素材或旧版JSON。
- 标签由离线关键词规则建议，允许人工修改，无外部AI请求。

## 数据与升级
数据库保存在 data/knowledge.db。首次启动载入6条示例素材、3个模板。
升级前关闭旧程序和旧浏览器页面，备份整个旧目录。
将新包解压到新目录，再复制旧目录的整个data文件夹到新目录合并。新包不含knowledge.db，不覆盖用户数据库。
启动新版，核对已有素材和模板。旧数据库首次启动自动增加账号表，不清空原数据。
CSV备份仅包含素材；恢复CSV会替换素材，保留现有模板。旧JSON备份恢复会替换素材及模板。
完整备份（包括模板、账号和历史）：停止程序后复制整个data文件夹。请保留升级前的旧目录以便回退。

## CSV使用
“维护与质量→下载CSV模板”后填写，每行一条素材；标题、正文、来源必填。
审核状态可填待审核/已审核/待更新，日期填YYYY-MM-DD；空白字段使用默认值，空白标签自动建议。
模板同时放在压缩包的docs/素材批量导入模板.csv，提供docs/素材批量导入示例.csv。
“批量导入CSV素材”只追加，忽略CSV中的负责人及编号；重复导入会追加重复素材。
“导入备份”读取CSV编号和负责人，用于恢复历史数据；会提前提示替换范围。

## 验证和开发
