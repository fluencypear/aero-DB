# aero-DB
航策 · 战略研究知识库 / 离线样机 v1.0

运行条件：Python 3.8或以上、现代浏览器。不需要联网，不需要pip安装。

Windows：解压整个压缩包（不要在压缩包内运行），双击start.bat。
会自动打开浏览器；若未打开，访问 http://127.0.0.1:8000 。
使用期间保持命令窗口打开，关闭窗口即可停止服务。
Mac/Linux：进入文件夹，运行 python3 server.py 。
如果8000端口被占用：python server.py --port 8001 。

建议体验顺序：
1. 在“素材与数据”检索并勾选素材。
2. 在“研究模板”编辑模板。
3. 在“报告工作台”输入课题并生成、编辑、导出草稿。
4. 在“拆解与整理”粘贴文字，填写来源，预览后入库。
5. 在“维护与质量”审核素材；已审核素材才会进入草稿。

数据：自动保存至data/knowledge.db，数据库初始化时装载示例资料。
每次修改前会在数据库history表中保存旧版本快照。
完整备份：关闭程序后复制整个data文件夹。
也可在维护页面导出JSON备份，再通过导入备份恢复（会替换现有数据）。
不要删除knowledge.db；首次运行后修改seed.json不会改变已有数据库。

功能边界：
这是单机离线样机。报告和模板采用规则生成，不包含大模型。
尚无企业内网AI接口、PDF/Word解析、语义检索、多用户权限。
服务仅监听127.0.0.1，不向其他电脑提供访问。
报告草稿下载为文本文件；草稿编辑内容不会自动写入数据库。
页面采用业务领域、业务类型标签；产出要求通过模板读者、篇幅、章节维护。
战略数据暂以文本保存，尚未提供数值字段校验。

仅内置示例资料，无外部字体、脚本、图片依赖，无遥测与联网请求。
本包未包含Python安装程序；电脑需要已安装Python。
